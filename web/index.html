如何获取 Authorization
  1. 点击上方链接，在减论官网正常登录。
  2. 按 F12 打开开发者工具，选择“网络 / Network”。
  3. 刷新热点页面，在请求列表里搜索 hot_list。
  4. 点击该请求，进入“标头 / Headers”，找到“请求标头 / Request Headers”。
  5. 复制 Authorization 的完整值，粘贴到上方输入框，点击保存。若值带 Bearer 前缀，请一并保留。

只复制值，不要包含 Authorization: 字段名。它相当于登录凭证，请勿分享。若提示登录过期，重新登录并按以上步骤更新。
